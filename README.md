# DevTools

[English](#english) · [Slovensky](#slovensky)

---

## English

A collection of developer tools for Android that mostly run locally on your device: HTTP requests, DNS, SSL/TLS certificates, CORS, caching, WebSocket, JWT, JSON, regular expressions, converters, a built-in browser with Chrome DevTools and more.

No ads, no analytics, no accounts, no tracking.

### Privacy

- Tools use the network only when needed, and only to the host you enter.
- DNS uses the resolver configured in your system.
- GeoIP is an offline database (IP Geolocation by [DB-IP](https://db-ip.com), licensed CC BY 4.0). No address is sent anywhere.
- The DevTools frontend is bundled with the app. Nothing is downloaded.
- The built-in browser uses DuckDuckGo as its default search engine.

### Languages

English and Slovak. The app follows the system language. You can change it in the side menu under Settings.

### Build

Requires JDK 17 and the Android SDK.

```
./gradlew assembleRelease
```

## Slovensky

Zbierka nástrojov pre vývojárov v Androide, ktoré väčšinou fungujú lokálne v zariadení: HTTP požiadavky, DNS, SSL/TLS certifikáty, CORS, cache, WebSocket, JWT, JSON, regulárne výrazy, konvertory, vstavaný prehliadač s Chrome DevTools a ďalšie.

Bez reklám, analytiky, účtov a sledovania.

### Súkromie

- Nástroje používajú sieť len vtedy, keď je to potrebné, a len na hostiteľa, ktorého zadáš.
- DNS používa resolver nastavený v systéme.
- GeoIP je offline databáza (IP Geolocation by [DB-IP](https://db-ip.com), licencia CC BY 4.0). Žiadna adresa sa nikam neposiela.
- DevTools frontend je súčasťou aplikácie. Nič sa nesťahuje.
- Vstavaný prehliadač používa ako predvolený vyhľadávač DuckDuckGo.

### Jazyky

Angličtina a slovenčina. Aplikácia používa jazyk systému. Zmeniť ho môžeš v bočnom menu v Nastaveniach.

### Zostavenie

Vyžaduje JDK 17 a Android SDK.

```
./gradlew assembleRelease
```
